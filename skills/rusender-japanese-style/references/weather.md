# Место, сезон и прогноз

Как получить данные для письма без скриптов. Источник прогноза — Open-Meteo (без ключа).
**Ничего не выдумывай:** нет данных — так и скажи.

## 1. Найди место

Запроси геокодер Open-Meteo инструментом загрузки веб-страниц (WebFetch и аналоги):

```
https://geocoding-api.open-meteo.com/v1/search?name=<город>&count=10&language=ru&format=json
```

Название города закодируй для URL. Если нужно ограничить страной — добавь `&countryCode=<ISO-код>`.

Разбор ответа (`results`):
- **Пусто** — место не найдено. Спроси пользователя, не угадывай.
- **Первый результат — страна** (`feature_code` начинается с `PCL`) — пользователь назвал страну.
  Назови её столицу и запроси ещё раз: `name=<столица>&countryCode=<country_code>`. Подходит
  только результат с `feature_code` = `PPLC`. Нет такого — спроси пользователя. Скажи, что
  погода взята по столице.
- **Город** — из результатов с `feature_code`, начинающимся на `PPL`, возьми самый населённый
  (`population`). Если есть одноимённые места, назови пользователю, какое взято (название +
  `admin1`), и упомяни до трёх других.

Запомни: `name`, `admin1`, `country`, `latitude`, `longitude`.

## 2. Определи сезон

Сезон берётся из `assets/seasons.json` по месяцу даты отправки:
- северное полушарие (`latitude ≥ 0`) — `months_north[месяц]`;
- южное (`latitude < 0`) — месяц сдвигается на 6: `(месяц + 5) mod 12 + 1`, затем
  `months_north[…]`.

Если `|latitude| < 23,44` — это тропики: предупреди пользователя, что четырёх сезонов там нет и
палитра выбрана по календарю полушария.

## 3. Возьми прогноз

Сколько дней от сегодня до даты отправки:
- дата в прошлом — прогноза нет;
- больше 15 дней — прогноза ещё нет, письмо пишется по сезону;
- иначе запроси:

```
https://api.open-meteo.com/v1/forecast?latitude=<lat>&longitude=<lon>&timezone=auto&forecast_days=16&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_sum,wind_speed_10m_max
```

В `daily.time` найди дату отправки и возьми значения с тем же индексом: `weather_code`,
`temperature_2m_min`, `temperature_2m_max`, `precipitation_sum`, `wind_speed_10m_max`.

## Если сервис недоступен

Если инструмент загрузки не открывает адрес или Open-Meteo не отвечает:
1. Попробуй найти прогноз на эту дату для этого города поиском по сайтам погоды.
2. Не нашёлся — скажи об этом и предложи на выбор: описать погоду самому или собрать письмо
   только по сезону.

Место и сезон без геокодера: если город однозначен и его полушарие очевидно, сезон можно
определить по дате; если нет — спроси пользователя.
